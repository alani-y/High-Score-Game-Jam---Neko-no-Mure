# Neko no Mure - 2D Unity Game Scripts

Welcome to the **Neko no Mure** GitHub repository! This repository contains the scripts for **Neko no Mure**, a charming 2D game made in Unity where players must search for cats that have escaped their house.

## 🐱 About the Game
In **Neko no Mure**, players take on the role of a cat owner whose feline friends have mysteriously escaped. The goal is to explore the environment and bring all the missing cats back home.
## 🔧 Requirements
To run and modify this project, you'll need:
- **Unity** (Recommended version: 2021.3 LTS or later)
- **C#** (for scripting)
- **Git** (for version control)

## 🚀 Getting Started
1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/NekoNoMure.git
   ```
2. Open the project in Unity.
3. Navigate to `Scenes/` and open the main scene.
4. Press `Play` in the Unity Editor to start testing the game.
